## 📦 FreshStock

Информационная система для автоматизации учета товаров на оптовом складе.

## 📋 Описание

Программа предназначена для ведения складского учета и включает следующий функционал:
- Управление каталогом товаров (добавление, редактирование, удаление)
- Оформление прихода и расхода товара
- Автоматический подсчет остатков
- Контроль минимальных остатков (предупреждение о дефиците)
- История всех складских операций
- Формирование отчетов по складу
- Экспорт данных

## 🚀 Возможности

✅ **Каталог товаров** — добавление и управление номенклатурой  
✅ **Приход товара** — оформление поступления на склад  
✅ **Расход товара** — оформление отгрузки со склада  
✅ **История операций** — полный журнал всех перемещений  
✅ **Отчеты** — статистика и аналитика по складу  
✅ **Контроль остатков** — автоматическое предупреждение о низких остатках  
✅ **Работа offline** — не требует подключения к интернету  
✅ **Портативная версия** — работает без установленного Python

## 🛠️ Технологии

- **Язык программирования:** Python 3.x
- **Графический интерфейс:** Tkinter
- **База данных:** SQLite
- **Сборка исполняемого файла:** PyInstaller
